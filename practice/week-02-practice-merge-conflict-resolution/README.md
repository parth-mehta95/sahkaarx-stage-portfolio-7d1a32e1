# Practice Merge Conflict Resolution

## Task Brief
Create intentional conflicts across feature branches, resolve them, and merge into develop using proper workflow.

## Scenario
Two team members modify the same Task class. Simulate conflict by creating feature branches, making conflicting edits, and resolving them.

## Deliverables
- Feature branches with conflicting changes
- Resolved merge commit in develop branch

## Success Criteria
- Conflicts identified and resolved correctly
- Clean git history with merge commit
