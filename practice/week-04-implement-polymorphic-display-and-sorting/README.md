## Task Brief
Override display and sort methods across task types; demonstrate method overriding and polymorphic behavior.

Task types need custom display formats and sorting logic. Override methods in UrgentTask and RecurringTask subclasses.

## Deliverables

- main.py calling polymorphic methods

## Success Criteria
- Each task type displays correctly
- Sorting works across all task types
