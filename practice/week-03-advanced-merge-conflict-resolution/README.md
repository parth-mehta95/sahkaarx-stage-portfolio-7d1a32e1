# Advanced Merge Conflict Resolution

## Task Brief
Simulate three-way merge conflicts across task type branches; practice resolution strategies and clean commit history.

## Scenario
Two team members modify task_types.py simultaneously. Create conflicting branches, resolve conflicts, and merge cleanly.

## Deliverables
- Two feature branches with conflicting edits
- Resolved merge commit in develop

## Success Criteria
- Conflicts resolved without losing code
- Clean git log with descriptive merge commit
